# Licence

The code (`lib/`, `scripts/`) and the tariff files are released under the MIT licence. The text is
in `LICENSE` at the root of the repository. The integration that copies `lib/` uses the same licence.

The tariff figures are prices that suppliers and regulators publish. The licence covers this
repository's own work: the code, the format, the way each tariff is written down and the indexes.
It does not claim ownership of the published figures. Each source's note in `sources/` says where its
figures come from and what that source says about reuse, so a user can check it.
